COMP 3008 Assignment 04 - Group 19 Implementation

How to run the implementation:
1. Open the terminal in the directory of the project
2. Run the command "npm install" to install the dependencies (Vite)
3. Run the command "npm run dev" to run the project
4. Open the localhost link displayed on the terminal to access the website

Dependencies:
Vite 8.3.6

Task instructions:
1. Once you have opened the website you can immediately begin the task by searching for "Dior"
2. After submitting the search you will be brought to a page displaying the results
3. Click on the top result (Sauvage Dior Eau de Toilette 2015)
4. You will be redirected to the product's page where you can look for the Main accords, Notes, and Similar fragrances to complete the task
